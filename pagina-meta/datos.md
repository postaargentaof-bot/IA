## Pasos
1. Facebook → Páginas → Crear página, con los datos de arriba.
2. En la página: Configuración → Cuentas vinculadas → Instagram: crear o conectar la cuenta.
3. Meta Business Suite («Ecom Manu») → Configuración → Cuentas → Páginas → Agregar → la página nueva.
4. En la misma configuración: Cuentas publicitarias → «Velas arg» → Asignar activos → sumar la página nueva.
5. Avisar al chat principal: verifica desde Meta que la página aparezca conectada a «Velas arg».
